# UniIDE

Онлайн-редактор кода для **Python**, **JavaScript** и **HTML** прямо в браузере. Ничего устанавливать не нужно.

## Возможности

- Три языка: Python, JavaScript, HTML (с CSS и JS файлами в одном проекте)
- Проекты из нескольких файлов: боковая панель, создание, переименование, удаление, скачивание
- **Загрузка любых файлов** кнопкой «Загрузить файл» или перетаскиванием в окно (до 25 МБ каждый): текстовые открываются в редакторе, картинки/видео/звук/архивы и прочее хранятся как есть и скачиваются без изменений. Загруженное доступно в HTML-предпросмотре (`<img src="photo.png">`, `url(font.woff2)`) и в Python через `open("имя")` (Pyodide)
- Редактор Ace с нумерацией строк, **вертикальными полосками отступов** и автодополнением (**Tab** — принять первую подсказку)
- Подсказки для Python, JavaScript, HTML (теги, атрибуты и их значения, шаблон `html5`) и CSS (свойства и значения); внутри `<style>` и `<script>` подсказки подстраиваются под CSS и JavaScript
- В HTML набор `</` сразу дописывает имя ближайшего открытого тега и `>`; теги, атрибуты и значения подсвечиваются разными цветами
- Размеры панелей меняются мышью или пальцем: потяните разделитель между файлами, кодом и терминалом (двойной щелчок — вернуть как было), размеры запоминаются
- Терминал с `input()` и командами `>>>`, вкладка «Проблемы» с подсветкой строки с ошибкой
- Python: полный Pyodide (в фоне) и лёгкий Skulpt для быстрого старта
- Лимит вывода 2 МБ и кнопка «Стоп» (при доступных Web Worker)
- Удобно на телефоне: компактная шапка, лента файлов, панель символов над клавиатурой (Tab, отмена, скобки, кавычки и др.), перетаскиваемая граница между кодом и терминалом
- При переименовании файла в HTML-проекте ссылки на него в других HTML-файлах обновляются сами
- Ошибки предпросмотра, включая необработанные Promise, попадают во вкладку «Проблемы»
- Проекты сохраняются на устройстве (localStorage), светлая и тёмная тема

## Запуск

Откройте `index.html` двойным щелчком в браузере. Нужен интернет: Ace, Skulpt и Pyodide загружаются с CDN.

> Лучше открывать файл напрямую, а не во встроенном предпросмотре: там могут быть заблокированы Web Worker и WebAssembly, и тогда полный Python (Pyodide) и «Стоп» недоступны.

## Структура

```
index.html            разметка страницы
manifest.json         установка на экран телефона (PWA)
.gitignore            что Git не должен загружать
css/
  base.css            цвета, темы, карточка приложения (~74% ширины экрана)
  header.css          шапка, переключатель языков, кнопки
  layout.css          боковая панель, редактор, терминал
  widgets.css         уведомления, окно подсказок, статус-бар
  editor.css          полоски отступов и цвета HTML-кода
  mobile.css          вид на телефоне и планшете, панель символов
img/
  logo.png            логотип в шапке сайта
  favicon.ico         иконка вкладки браузера (16/32/48 px)
  favicon-32.png      иконка вкладки (PNG)
  apple-touch-icon.png  иконка для iPhone/iPad
  icon-192.png        иконка для Android (подключена через manifest.json)
js/                   подключаются в указанном порядке
  01-files.js         элементы страницы, файлы проекта по умолчанию
  02-editor.js        редактор Ace, тема, сохранение в localStorage
  03-autocomplete.js  база подсказок (Python, JavaScript, HTML, CSS)
  04-sidebar.js       панель файлов: создать, переименовать, закрыть
  05-terminal.js      вкладки вывода, «Проблемы», терминал, лимит 2 МБ
  06-workers.js       Web Worker'ы, кнопка «Стоп», режим совместимости
  07-python.js        Skulpt и Pyodide
  08-python-start.js  запуск Python
  09-javascript.js    запуск JavaScript
  10-html-preview.js  сборка HTML-предпросмотра
  11-main.js          кнопка «Запустить» и старт приложения
  12-html-tools.js    закрытие тегов по «</», определение, где курсор (HTML / style / script)
  13-layout.js        перетаскиваемые разделители панелей
  14-mobile.js        панель символов для телефона
  15-upload.js        загрузка файлов: кнопка и перетаскивание
```

Скрипты обычные (не модули) и делят общую область видимости, поэтому порядок подключения в `index.html` важен.

## Публикация на GitHub Pages

1. Загрузите папку в репозиторий.
2. Settings → Pages → Source: ветка `main`, папка `/ (root)`.
3. Сайт откроется по адресу `https://ваш-ник.github.io/название-репозитория/`.
