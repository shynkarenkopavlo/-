# UniIDE

Онлайн-редактор кода для **Python**, **JavaScript** и **HTML** прямо в браузере. Ничего устанавливать не нужно.

## Возможности

- Три языка: Python, JavaScript, HTML (с CSS и JS файлами в одном проекте)
- Проекты из нескольких файлов: боковая панель, создание, переименование, удаление, скачивание
- Редактор Ace с нумерацией строк и автодополнением (**Tab** — принять первую подсказку)
- Терминал с `input()` и командами `>>>`, вкладка «Проблемы» с подсветкой строки с ошибкой
- Python: полный Pyodide (в фоне) и лёгкий Skulpt для быстрого старта
- Лимит вывода 2 МБ и кнопка «Стоп» (при доступных Web Worker)
- Проекты сохраняются на устройстве (localStorage), светлая и тёмная тема

## Запуск

Откройте `index.html` двойным щелчком в браузере. Нужен интернет: Ace, Skulpt и Pyodide загружаются с CDN.

> Лучше открывать файл напрямую, а не во встроенном предпросмотре: там могут быть заблокированы Web Worker и WebAssembly, и тогда полный Python (Pyodide) и «Стоп» недоступны.

## Структура

```
index.html            разметка страницы
css/
  base.css            цвета, темы, карточка приложения (~74% ширины экрана)
  header.css          шапка, переключатель языков, кнопки
  layout.css          боковая панель, редактор, терминал
  widgets.css         уведомления, окно подсказок, статус-бар
js/                   подключаются в указанном порядке
  01-files.js         элементы страницы, файлы проекта по умолчанию
  02-editor.js        редактор Ace, тема, сохранение в localStorage
  03-autocomplete.js  база подсказок (Python, JavaScript, HTML, CSS)
  04-sidebar.js       панель файлов: создать, переименовать, закрыть
  05-terminal.js      вкладки вывода, «Проблемы», терминал, лимит 2 МБ
  06-workers.js       Web Worker'ы, кнопка «Стоп», режим совместимости
  07-python.js        Skulpt и Pyodide
  08-python-start.js  запуск Python
  09-javascript.js    запуск JavaScript
  10-html-preview.js  сборка HTML-предпросмотра
  11-main.js          кнопка «Запустить» и старт приложения
```

Скрипты обычные (не модули) и делят общую область видимости, поэтому порядок подключения в `index.html` важен.

## Публикация на GitHub Pages

1. Загрузите папку в репозиторий.
2. Settings → Pages → Source: ветка `main`, папка `/ (root)`.
3. Сайт откроется по адресу `https://ваш-ник.github.io/название-репозитория/`.
